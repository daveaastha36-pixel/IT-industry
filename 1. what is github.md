##Github is web based platform for storing , managing , and collabrating on software projects using git, a version control system .##


****What github is used for ****
version control : keep complete history of changes to your code and revert to earlier versions if needed.
Collabration : multiple people can work on the same project without overwritting each other's work.
Code hosting : store repositories in the cloud .
Code review : team members can review proposed changes using pull requests before they're merged.
Issue tracking : report bugs, request features , and rocognize work.
Automation : run tests, build software , or deploy applications automaqtically with github actions.
